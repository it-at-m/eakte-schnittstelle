# DMS (eAkte)

This page describes various generic DMS (eAkte) topics.

## Resources

The structure of the different resources is described in the following in the format `English name (German name)`.

Fileplan (Aktenplan) → n \* Apentry (Aktenplaneintrag) → SubjectArea (Aktenplaneintrag (Betreffseinheit)) → File (Sachakte) →
Procedure (Vorgang) → Document (Dokument) → ContentObject (Schriftstück)

Document-Types: Incoming (Eingang), Outgoing (Ausgang/Erledigung), Internal (Internes)
