# Introduction and Goals

The eAkte-API-V2 is a reimplementation of the V1 with the main goal of decoupling the implementation from LHM-particularities.
The number of separate interfaces to the DMS is to be reduced and all remaining components are to be based on state-of-the-art technologies and protocols.

## Requirements Overview

## Quality Goals

1. maintainability (specifically: reduce dependency on manufacturer and reduce development time frame and costs)
2. security (specifically: ensure maximum of audit compliance by implementing an end-to-end authorization mechanism)
3. usability (specifically: provide self-explanatory state-of-the art API and reduce consulting effort)
4. interoperability (specifically: reduce technical overhead and costs for connecting other systems to the DMS)
